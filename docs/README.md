## Convenções

Os documentos devem registrar somente informações verificáveis, decisões aprovadas e hipóteses identificadas como tal. Métricas da LP não podem ser preenchidas com resultados simulados. Antes de tornar o repositório público, revise estas notas para remover links privados, dados pessoais não necessários, credenciais, segredos e referências a ambientes de produção.

O repositório do agente G10 deve manter sua própria pasta `docs/`, README, DEVLOG e evidências. Esta documentação pertence à LP de showcase e não substitui a documentação técnica do MVP acadêmico.
